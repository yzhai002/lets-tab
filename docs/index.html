核心功能

🧩

一键合并同类项

点击插件图标，相同网站的标签页自动收进同名彩色分组，标签栏瞬间清爽。

🔥

关闭重复网页

智能识别相同 URL（自动忽略 #锚点、utm_* 等追踪参数），只保留最早打开的那一个。

📌

保护你的固定标签

固定的（Pinned）标签页和黑名单网站不参与整理，重要页面永被误伤。

🔒

100% 本地处理

所有标签数据只在你的浏览器里计算，零网络请求，不上传任何信息。

🪶

轻量无依赖

Manifest V3 原生实现，仅申请 tabs 与 storage 两项权限，安装即用。

🌐

双浏览器支持

同一套代码直接跑在 Chrome 和 Edge 上，数据经浏览器账号同步。

安装使用

下载源码

从 GitHub 仓库 下载并解压到本地任意文件夹。

打开扩展管理页

Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。

开启开发者模式

打开页面右上角的「开发者模式」开关。

加载扩展

点「加载已解压的扩展程序」，选择仓库里的 extension/ 文件夹，完成。

常见问题

两个网址看起来一样，为什么没被判为重复？

可以在设置页里调整判定规则：是否忽略 #锚点、追踪参数（utm_* 等）、末尾斜杠。例如 /page/ 与 /page 默认视为相同。

会不会把我不想关的页面关掉？

不会。固定（Pinned）的标签页永远保留；你也可以在设置里把常用网站加入黑名单（如正在编辑的在线文档），黑名单网站完全不参与整理。

我的标签数据安全吗？

安全。LetsTab 没有任何服务器，不发起网络请求，全部逻辑在浏览器本地完成，设置数据仅通过浏览器自带的同步机制保存。
