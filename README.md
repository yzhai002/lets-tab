# LetsTab

一键整理浏览器标签页：相同网站自动合并分组，重复网页一键关闭。支持 **Chrome** 与 **Edge**。

## 功能

- 🧩 **一键合并同类项** — 相同域名的标签页收进同名彩色分组
- 🔥 **关闭重复网页** — URL 规范化后完全相同即判重，只保留最早打开的（自动忽略 `#锚点`、`utm_*` 等追踪参数）
- ⌨️ **全局快捷键** — `Alt+G` 一键合并分组、`Alt+D` 关闭重复、可自定义
- 📂 **快照** — 保存当前所有标签页（含分组），随时恢复；上限 20 条
- 📐 **自定义分组规则** — `域名|域名2 => 组名`，把相关网站归并成一组并起名（如「B站」「开发」）
- 🔍 **标签搜索** — popup 顶部实时过滤标签页和网站
- 📌 **保护规则** — 固定（Pinned）的标签页不参与整理；支持网站黑名单
- 🔒 **100% 本地处理** — 零网络请求，不上传任何数据
- 🪶 **轻量** — Manifest V3，仅 `tabs` + `tabGroups` + `storage` 三项权限，无任何依赖

## 安装（开发者模式）

1. 下载或 clone 本仓库
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择本仓库的 `extension/` 文件夹

## 使用

点击工具栏的 LetsTab 图标，弹窗中：

- **一键合并分组**：把当前窗口里相同网站的标签页收进彩色分组
- **关闭重复**：跨窗口检测所有重复标签页并一键关闭（保留最早打开的）
- **📸 快照**：把当前所有标签页（含分组结构）存为快照，底部「历史快照」可恢复/删除
- 顶部**搜索框**实时过滤；每个网站分组可点击头部折叠/展开（≥5 个标签默认折叠）
- 图标上的红色角标实时显示当前重复标签页数量
- 每个网站分组旁可以单独"分组"该网站；标签行可点击跳转、可单独关闭

**快捷键**：`Alt+G` 合并分组、`Alt+D` 关闭重复（可在 `chrome://extensions/shortcuts` 改键）。

设置页（⚙️）可调整：重复判定规则（锚点 / 追踪参数 / 末尾斜杠）、固定标签保护、网站黑名单、自定义分组规则（`域名|域名2 => 组名`）。

## 目录结构

```
extension/          # 插件本体（加载这个文件夹）
├── manifest.json   # MV3 配置
├── background.js   # Service Worker：重复数量角标
├── src/lib.js      # 核心逻辑：URL 规范化、聚合、去重
├── popup/          # 点击图标的管理界面
├── options/        # 设置页
└── icons/          # 图标
docs/index.html     # Landing page（GitHub Pages）
```
